tagline: Ein Quality-of-Life-Mod für Fabric.
why: An echte Spieler ausgeliefert und wird noch immer heruntergeladen.
built:
  problem: Serverbetreiber brauchen einen Weg, Module abzuschalten, die sie nicht erlauben, ohne dass Spieler ihre Installation ändern.
  solution: Der Server schickt eine Plugin-Nachricht auf dem Kanal helix:config mit einer JSON-Liste von Modul-IDs; Helix schaltet diese Module ab, bis der Spieler neu beitritt. Ungültiges JSON und unbekannte IDs werden ignoriert.
badgeLabel: Downloads auf Modrinth

  note: 10 Releases zwischen 14. Apr. und 31. Mai 2024, Fabric, Minecraft 1.20.4 und 1.20.5

- Helix-Einstellungen im Spiel

- Helix-Hotbar
